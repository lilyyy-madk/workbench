# 个人专属工作台 · 使用说明

## 文件结构

```
/workspace/workbench/
├── index.html   # 应用入口与布局骨架
├── style.css    # 全部样式、响应式断点、动画
├── utils.js     # 工具库、食物数据库、饮品类型、学习语录
└── app.js       # 5 大功能模块与主应用逻辑
```

## 快速启动

1. 进入目录：`cd /workspace/workbench`
2. 启动本地服务器：`python3.11 -m http.server 8080`
3. 浏览器打开：`http://localhost:8080`

> 直接双击 `index.html` 在浏览器打开也可以，但 localStorage 在部分浏览器 file 协议下可能受限，推荐用本地服务器访问。

## 已完成功能

| 模块 | 核心功能 | 本地存储键 |
|------|----------|------------|
| 待办事项 | 每日随机 4 个预设任务、自定义添加、勾选/删除、顶部进度 | `todos_YYYY-MM-DD` |
| 喝水提醒 | 1000ml 目标、圆环进度、6 种饮品选择、月历查看、9:30/15:30 提醒 | `water_YYYY-MM-DD` |
| 饮食记录 | 四餐次切换、27 种食物数据库、自动热量估算、自定义食材、历史日历 | `diet_YYYY-MM-DD` |
| 每日学习 | 任务清单、学习时长汇总、19:00 提醒、20:00 未完成全屏弹窗 | `study_YYYY-MM-DD` |
| 健身计划 | 周目标 120 分钟、倒计时/暂停/提前完成、本月达标日历 | `fitness_YYYY-MM-DD` |
| 设置 | 通知开关、侧边栏折叠、数据导出/清除 | `app_settings` |

## 响应式布局

- **iPad / 桌面**：左侧固定纵向导航栏，图标 + 文字，底部设置入口。
- **手机（< 768px）**：顶部汉堡菜单 + 左侧可折叠侧边栏，底部固定 5 项 Tab 栏。

## 通知提醒

- 首次点击通知开关会请求浏览器桌面通知权限。
- 若权限被拒绝，自动降级为应用内 Toast 提示。
- 前台运行时每分钟检测一次时间，触发喝水 / 学习提醒。

## 数据说明

- 所有数据按日期为键存入 `localStorage`。
- 首次加载或日期变化时自动执行每日重置（保留历史数据）。
- 可在「设置」页面导出 JSON 备份或清除全部数据。
